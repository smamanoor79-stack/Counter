# Counter Project

A lightweight counter web app built with HTML, CSS, and JavaScript.

> A simple interactive counter that lets you increment, decrement, reset, and even save and reload your count — perfect as a tally tool or a beginner JavaScript project.

## Features

- **Increment / Decrement** — Increase or decrease the count with the `+` and `-` buttons
- **Reset** — Return the counter to zero instantly
- **Save** — Persist the current count (via `counter.js` logic)
- **Load** — Restore a previously saved count
- **Message display** — A feedback area that shows status messages to the user

## Usage

Open `counter.html` in any modern browser. Keep `counter.css` and `counter.js` in the same folder.

| Button | Action |
|--------|--------|
| `+` | Increase count by 1 |
| `-` | Decrease count by 1 |
| `Reset` | Set count back to 0 |
| `Save` | Save the current count |
| `Load` | Load the last saved count |

## File Structure

```
├── index.html   # Markup and layout
├── style.css    # Styles (external)
└── script.js     # Counter logic (external)
```

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge) with no build step or internet connection required.
